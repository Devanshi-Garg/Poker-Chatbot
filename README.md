Our Goal:
We have designed this Poker Chatbot/Simulator Website to help newer players of Texas 
Hold'em poker understand the strategy of the game better and make better informed decisions.

End User:
We have designed this website to help Beginner to Intermediate level poker players wanting to
get better at Texas Hold'em.

Tools:
The code for this website was primarily created by Gemini, along with other AI assistants like
ChatGPT, Claude, etc. helping split the code and making it easier to understand. 

Overall Process:
We got the base version of our website was created by Gemini, which was later improved upon
with specifications that we wanted for our website. Some examples of this includes how the cards 
visually look as well as the process for how results are given.
